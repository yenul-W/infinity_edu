Part A

The Gradient-Intercept Formula

Definition — Gradient-Intercept Form

The gradient-intercept form of a linear equation is:

\[y = mx + b\]
  • \(m\) is the gradient — it controls the steepness and direction of the line.
  • \(b\) is the y-intercept — the value of y where the line crosses the y-axis (when \(x = 0\)).

When an equation is in this form, you can read off \(m\) and \(b\) directly without any calculation.

Worked Example — Sketching a line

Sketch the line \(y = 3x - 2\).

  1. Identify \(b = -2\). Plot the y-intercept at \((0, -2)\).
  2. Identify \(m = 3\). From \((0, -2)\) move 1 unit right and 3 units up. Plot the second point at \((1, 1)\).
  3. Draw a straight line through the two points and extend with arrows.

You can verify: when \(x = 2\), \(y = 3(2) - 2 = 4\). The point \((2, 4)\) should lie on your line.

Part A (continued)

Rearranging into Gradient-Intercept Form

Many linear equations are not given in \(y = mx + b\) form. You need to rearrange them before you can read off the gradient and y-intercept.

Worked Example

Find the gradient and y-intercept of \(x - 2y + 6 = 0\).

Rearrange to make y the subject:

\(x - 2y + 6 = 0\)

\(-2y = -x - 6\)

\(y = \dfrac{1}{2}x + 3\)

So \(m = \dfrac{1}{2}\) and \(b = 3\). The line has a positive gradient and crosses the y-axis at 3.

Remember: Divide every term by the coefficient of y, including the sign. If dividing by a negative number, the inequality (if present) would flip — but for equations, just proceed carefully with signs.

Part B

Linear Models

Definition — Linear Model

A linear model uses a linear equation to describe a real-world relationship. Once you write the equation, you can predict output values for any input.

In a linear model \(y = mx + b\):

ParameterMeaning in a real-world modelExample
\(m\) (gradient)Rate of change — how much y changes per unit of x$2 per kilometre driven
\(b\) (y-intercept)Fixed starting value — the value of y when x = 0$3 flag fall before the taxi moves

Example 1 — Taxi fare

A taxi charges a flag fall of $3 and then $2 per kilometre. Complete the table, find the equation, and answer the questions.

Distance (K km)01020304050
Cost (C $)
\(C =\) ✓ C = 2K + 3
$ ✓ $39 (C = 2×18 + 3 = 39)

Answer: The gradient (\(m = 2\)) represents the cost per kilometre — $2 for every km travelled. The y-intercept (\(b = 3\)) is the flag fall — the fixed charge you pay just to get in the taxi.

Example 2 — Paying off a debt

Jim borrowed $8 000 and pays back $200 each week. Complete the table, find the equation, and answer the question.

Weeks (W)0510203040
Debt (D $)
\(D =\) ✓ D = −200W + 8000
$ ✓ $2 600 (D = −200×27 + 8000 = 2600)

Example 3 — Phone plan

A phone plan charges a flat monthly fee of $20 plus $0.10 per minute of calls. Let M be minutes used and C be the monthly cost in dollars.

Setting up the model

  • Fixed charge (y-intercept): \(b = 20\)
  • Rate of change (gradient): \(m = 0.10\) per minute
  • Equation: \(C = 0.10M + 20\)
\(C =\) $ ✓ $35 (C = 0.10 × 150 + 20 = 15 + 20 = 35)
\(M =\) ✓ 120 min (32 = 0.10M + 20 → 0.10M = 12 → M = 120)
