Quick Reference

Key Formulas & Concepts

Lesson 1 — Graphing & Gradient

  • m = rise / run= (y₂ − y₁) / (x₂ − x₁)
  • Positive m → rises left-to-right↗
  • Negative m → falls left-to-right↘
  • y-intercept = y when x = 0denoted b

Lesson 2 — Gradient-Intercept

  • y = mx + bgradient-intercept form
  • m = gradient (slope)controls steepness and direction
  • b = y-interceptwhere line crosses y-axis
  • Linear model: C = mK + be.g. C = 2K + 3 for taxi

Lesson 3 — Direct Variation

  • y = kxk = constant of variation
  • Graph through origin (0, 0)essential property
  • k = y / xdivide any (x, y) pair
  • y = mx + b is NOT direct variation if b ≠ 0

Common Mistakes to Avoid

  • ! Confusing rise and run — rise is vertical (y), run is horizontal (x).
  • ! Forgetting to rearrange before reading m and b (e.g. y = 5 − x → m = −1, not 5).
  • ! Calling y = 2x + 3 direct variation — it has b = 3 ≠ 0, so it's NOT direct variation.
  • ! Sign errors: m = (y₂ − y₁)/(x₂ − x₁), not (y₁ − y₂)/(x₂ − x₁).
  • ! In a linear model, gradient = rate of change, y-intercept = starting/fixed value.

Question 1 · Graphing

What is the gradient of a line that passes through (−2, 4) and (3, −6)?

A 2
B −2
C 10
D −10
Answer: B — −2
rise = −6 − 4 = −10, run = 3 − (−2) = 5.
m = −10/5 = −2.

Question 2 · Gradient-Intercept

The equation 3x − y + 6 = 0 can be rewritten as y = mx + b. What are m and b?

A m = 3, b = 6
B m = −3, b = 6
C m = 3, b = −6
D m = −3, b = −6
Answer: A — m = 3, b = 6
3x − y + 6 = 0 → y = 3x + 6. So m = 3, b = 6.

Question 3 · Direct Variation

Which of these is an example of direct variation?

A C = 3K + 5 (taxi with flag fall)
B D = 8000 − 200W (decreasing debt)
C E = 23.5h (earnings: $23.50/hr)
D T = 50 (constant temperature)
Answer: C — E = 23.5h
Direct variation: y = kx, passing through origin. E = 23.5h passes through (0,0) ✓.
Option A has b = 5 ✗. Option B has b = 8000 ✗. Option D is a constant ✗.

Question 4 · Linear Models

A plumber charges a $60 call-out fee plus $80 per hour. Which equation gives total cost C for h hours?

A C = 80h
B C = 60h + 80
C C = 80h + 60
D C = 60 + h
Answer: C — C = 80h + 60
$80 per hour → gradient = 80. $60 call-out fee → y-intercept = 60. C = 80h + 60.

Question 5 · Gradient

A table of values for a linear function shows: x = 0 → y = 3, and x = 4 → y = 11. What is the gradient?

A 0.5
B 2
C 3
D 4
Answer: B — gradient = 2
rise = 11 − 3 = 8, run = 4 − 0 = 4. m = 8/4 = 2.

Question 6 · Direct Variation

The distance a car travels varies directly with fuel used. It travels 320 km on 25 L. How far on 40 L?

A 480 km
B 512 km
C 560 km
D 640 km
Answer: B — 512 km
k = 320/25 = 12.8 km/L. D = 12.8 × 40 = 512 km.

Question 7 · Equations

A line has equation y = −½x + 4. At what x-value does it cross the x-axis?

A x = 4
B x = 8
C x = −8
D x = 2
Answer: B — x = 8
Set y = 0: 0 = −½x + 4 → ½x = 4 → x = 8.

Question 8 · Linear Models

Using C = 80h + 60 from Q4, how many hours did a $300 job take?

A 2.5 hours
B 3 hours
C 3.5 hours
D 4 hours
Answer: B — 3 hours
300 = 80h + 60 → 80h = 240 → h = 3.

Question 9 · Gradient-Intercept

Two lines y = 2x + 3 and y = 2x − 5 are graphed. Which statement is true?

A They are perpendicular
B They intersect at x = 1
C They are parallel (never meet)
D They have the same y-intercept
Answer: C — They are parallel
Both lines have m = 2 (same gradient), but different y-intercepts (3 and −5). Parallel lines never intersect.

Question 10 · Mixed

Petrol costs vary directly with litres purchased. 20 L costs $36. What is the equation for cost C (in dollars) for L litres?

A C = 0.55L
B C = 1.80L
C C = 36L + 20
D C = 1.80L + 36
Answer: B — C = 1.80L
k = 36/20 = 1.80 ($/L). Direct variation: C = 1.80L.
