Question 1 Lesson 1

In the diagram, a line passes through \((0, 6)\) and \((2, 0)\). What is the gradient?

A \(-6\)
B \(-3\)
C \(2\)
D \(3\)
Answer: B — gradient \(= -3\)
\(m = \dfrac{\text{rise}}{\text{run}} = \dfrac{0 - 6}{2 - 0} = \dfrac{-6}{2} = -3\). The line falls from left to right.

Question 2 Lesson 1

A line passes through \((-4, 0)\) and \((0, 12)\). What is the gradient?

A \(-3\)
B \(-2\)
C \(3\)
D \(4\)
Answer: C — gradient \(= 3\)
\(m = \dfrac{12 - 0}{0 - (-4)} = \dfrac{12}{4} = 3\). Positive — rising left to right.

Question 3 Lesson 2

A straight line has equation \(x - 2y + 6 = 0\). Which statement is true?

A gradient \(= -\tfrac{1}{2}\) and \(y\)-intercept \(= 3\)
B gradient \(= 2\) and \(y\)-intercept \(= -3\)
C gradient \(= 2\) and \(y\)-intercept \(= 3\)
D gradient \(= \tfrac{1}{2}\) and \(y\)-intercept \(= 3\)
Answer: D
Rearrange: \(2y = x + 6\), so \(y = \tfrac{1}{2}x + 3\). Gradient \(= \tfrac{1}{2}\), \(y\)-intercept \(= 3\).

Question 4 Lesson 2

Tommy draws \(y = 5 - 2x\). Which sketch is correct?

A Falls left-to-right, \(y\)-intercept at 5
B Rises left-to-right, \(y\)-intercept at 5
C Falls left-to-right, \(y\)-intercept at \(-5\)
D Rises left-to-right, \(y\)-intercept at \(-5\)
Answer: A
\(y = -2x + 5\). Gradient \(= -2\) (falls left to right), \(y\)-intercept \(= 5\).

Question 5 Lesson 3

\(V\) and \(W\) vary directly. \(W = 92.0\) when \(V = 36.8\). Which equation describes this?

A \(W = 1.5V\)
B \(W = 2.5V\)
C \(W = 5.0V\)
D \(W = 55.2V\)
Answer: B — \(W = 2.5V\)
\(k = \dfrac{W}{V} = \dfrac{92.0}{36.8} = 2.5\).

Question 6 Lesson 3

A graph shows \(M\) vs \(N\). Points \((0, 4)\) and \((2, 10)\) lie on the line. What is its equation?

A \(M = 3N + 4\)
B \(M = 0.6N + 4\)
C \(M = 4N + 0.6\)
D \(M = 4N + 3\)
Answer: A — \(M = 3N + 4\)
\(m = \dfrac{10 - 4}{2 - 0} = \dfrac{6}{2} = 3\). \(y\)-intercept \(= 4\) (from point \((0, 4)\)). Equation: \(M = 3N + 4\).

Question 7 Lesson 3

Two relationships are graphed. Relationship X passes through the origin. Relationship Y has a \(y\)-intercept of 8. Which is direct variation?

A Both relationships
B Neither relationship
C Relationship X only
D Relationship Y only
Answer: C — Relationship X only
Direct variation requires the graph to pass through the origin \((0, 0)\). Relationship X does; Y has \(y\)-intercept \(= 8 \neq 0\).

Question 8 Lesson 1

Which graph represents \(y = 2x - 4\)?

A Negative gradient, \(y\)-intercept at 4, \(x\)-intercept at 2
B Positive gradient, \(y\)-intercept at 4, \(x\)-intercept at \(-2\)
C Negative gradient, \(x\)-intercept at \(-2\), \(y\)-intercept at \(-4\)
D Positive gradient, \(x\)-intercept at 2, \(y\)-intercept at \(-4\)
Answer: D
\(m = 2\) (positive). \(y\)-intercept: set \(x = 0 \Rightarrow y = -4\). \(x\)-intercept: set \(y = 0 \Rightarrow 2x = 4 \Rightarrow x = 2\).

Question 9 Lesson 2

A line has gradient \(-3\) and \(y\)-intercept \(4\). What is its equation?

A \(y = 4 - 3x\)
B \(y = 4x - 3\)
C \(y = 3 - 4x\)
D \(y = 3x - 4\)
Answer: A — \(y = 4 - 3x\)

Question 10 Lesson 3

A fuel pump delivers 50 L in 60 seconds (graph passes through origin). How long to fill 80 litres?

A 1 minute and 20 seconds
B 1 minute and 30 seconds
C 1 minute and 40 seconds
D 2 minutes
Answer: C — 1 minute and 40 seconds
\(k = \dfrac{50}{60} \approx 0.833\) L/s. Solve \(80 = 0.833T \Rightarrow T \approx 96\) s \(= 1\) min 36 s. Using the exact rate: \(k = \dfrac{5}{6}\), \(T = 80 \div \dfrac{5}{6} = 96\) s \(\approx 1\) min 40 s.

\(m = \dfrac{140 - 32}{60 - 0} = \dfrac{108}{60} = 1.8\)
