Theory

What Is a Network?

A network (also called a graph) is a collection of objects, called vertices, connected by lines called edges. Networks are used to model countless real-world systems:

  • Road networks — towns/intersections are vertices, roads are edges
  • Social networks — people are vertices, friendships/connections are edges
  • Computer networks — devices are vertices, cables/wireless links are edges
  • Utility networks — substations or pumping stations are vertices, power lines or pipes are edges

Network Terminology

Two key words describe every network:

  • Vertex (plural: vertices) — an object or point in the network, shown as a circle/dot
  • Edge — a line connecting two vertices, representing a direct connection between them

In the diagram above, A, B, C, D and E are vertices, and each line segment (e.g. A–B, B–C) is an edge. Not every pair of vertices needs to be directly connected — for example, A and C are not directly joined by an edge.

Connected Graphs

A network is connected if there is a path between every pair of vertices — you can get from any vertex to any other vertex by travelling along edges. A network is disconnected if at least one pair of vertices has no such path between them.

Connected — every vertex is reachable from every other

Disconnected — no path exists between {W,X} and {Y,Z}

Worked Example

In the disconnected diagram above, is there a path from W to Y?

No — W and X are only connected to each other, and Y and Z are only connected to each other. There is no edge (or chain of edges) joining the two pairs, so the network is disconnected and no W–Y path exists.

Theory

Isomorphic Graphs

Two networks are isomorphic if they have exactly the same structure — a one-to-one correspondence between their vertices that preserves every edge — even if they are drawn differently, rotated, or use different vertex labels. Isomorphic graphs are "the same network" in disguise.

Drawn as a square: 1–2–3–4–1

Drawn as a diamond: a–b–c–d–a

Worked Example

Show that these two graphs are isomorphic.

Match \(1\leftrightarrow a\), \(2\leftrightarrow b\), \(3\leftrightarrow c\), \(4\leftrightarrow d\). Every edge in the square graph (1–2, 2–3, 3–4, 4–1) corresponds to an edge in the diamond graph (a–b, b–c, c–d, d–a) under this matching, so the two graphs are isomorphic — they're the same 4-cycle, just drawn differently.

Note: two graphs having the same degree sequence is necessary for them to be isomorphic, but not sufficient — you still need to check that a matching exists which preserves every edge.

Weighted and Directed Networks

Networks can carry extra information:

  • A weighted network labels each edge with a number (the "weight") — e.g. distance, cost, or time.
  • A directed network uses arrows to show that a connection only goes one way (e.g. a one-way street).

The diagram below is both weighted and directed: each arrow shows the direction of travel, and each number is the weight of that edge.

A weighted, directed network: P→Q (7), Q→R (4), P→S (9), S→R (6)

Worked Example

Using the diagram above, what is the total weight of travelling from P to R via S (i.e. P → S → R)?

P → S has weight 9, and S → R has weight 6. Total \(= 9 + 6 = 15\).

Degree of a Vertex

The degree of a vertex is the number of edges connected to it. In the diagram below, vertex X is connected to four other vertices, so X has degree 4.

deg(X) = 4, since 4 edges meet at X. Vertex A also connects to E, so deg(A) = 2.

Worked Example

What is the degree of vertex D in the diagram above?

D has only one edge (to X), so \(\deg(D) = 1\).

Constructing Diagrams from Tables

Networks are often given as a table of distances (or costs, or times) between locations. To draw the network, place a vertex for each location, then draw an edge — labelled with its weight — for each entry in the table.

RouteDistance (km)
Alder – Birchwood12
Alder – Cedar18
Birchwood – Cedar9
Birchwood – Dunmore15
Cedar – Dunmore11

There is no direct road between Alder and Dunmore, so no edge is drawn between them. The resulting network diagram is:

A = Alder, B = Birchwood, C = Cedar, D = Dunmore (distances in km)

Worked Example

Using the network above, what is the total distance travelling from Alder to Dunmore via Birchwood (A → B → D)?

A–B is 12 km and B–D is 15 km. Total \(= 12 + 15 = 27\) km.

Worked Example

What is the degree of Birchwood (B) in this network?

B connects to A, C and D, so \(\deg(B) = 3\).
