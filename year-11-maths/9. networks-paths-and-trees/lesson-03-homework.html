Question 1 Lesson 1

A network has vertices P, Q, R connected by edges P–Q, Q–R and P–R. What is deg(Q)?

1
2
3
4
Answer: B — 2
Q connects to P (via P–Q) and R (via Q–R), so deg(Q) = 2.

Question 2 Lesson 1

Which statement correctly describes an edge?

A connection between two vertices
An object in a network
The weight of a route
The number of vertices in a network
Answer: A
An edge is a line representing a connection between two vertices.

Question 3 Lesson 1

A directed edge points from vertex X to vertex Y. What does this mean?

X and Y have the same degree
X and Y are not connected
Travel is only possible from X to Y, not Y to X
The edge has no weight
Answer: C
A directed edge only allows travel in the direction of the arrow, like a one-way street.

Question 4 Lesson 1

Towns M and N have no entry in a distance table between them. What does this mean for the network diagram?

M and N must be connected via every other town
M and N are drawn as the same vertex
M and N have degree 0
There is no direct edge between M and N
Answer: D
No table entry means no direct edge is drawn — M and N may still be reachable via other vertices.

30

Answer: B — 11
Total \(= 6 + 5 = 11\).

Question 6 Lesson 2

Which statement about a tree is true?

It is connected and has no cycles
It must contain a cycle
It must be a directed network
It has more edges than vertices
Answer: A
A tree is a connected network with no cycles.

Question 7 Lesson 2

A spanning tree of a network with 7 vertices has how many edges?

5
7
8
6
Answer: D — 6
A spanning tree of a network with \(n\) vertices always has \(n - 1\) edges: \(7 - 1 = 6\).

Question 8 Lesson 2

When building a minimum spanning tree by adding edges from smallest to largest weight, an edge is skipped if:

it has the smallest weight
it connects two new vertices
it would create a cycle
it is directed
Answer: C
Any edge that would create a cycle with already-chosen edges is skipped.

Question 9 Lesson 2

Route X–Y–Z has total weight \(3 + 4 = 7\). The direct edge X–Z has weight 5. What is the shortest path from X to Z?

Direct edge X–Z, weight 5
Route X–Y–Z, weight 7
Both routes are equally short
Cannot be determined
Answer: A
5 is less than 7, so the direct edge X–Z is the shortest path.

Question 10 Lesson 2

Why might the shortest path between two vertices NOT be part of any minimum spanning tree?

The MST always contains the shortest path
The MST minimises total weight overall, which can exclude an edge that's individually the cheapest link between one specific pair
Shortest paths are never part of any tree
MSTs only apply to directed networks
Answer: B
An MST minimises the total weight connecting every vertex, which can exclude an edge that happens to be the cheapest route between one particular pair.

Question 11 3 marks Lesson 1

A network has vertices Home (H), School (S), Park (P) and Library (L), with direct roads H–S (3 km), H–P (5 km), S–L (4 km), P–L (2 km).

(a) What is deg(H)? 1
H connects to S and P, so deg(H) = 2.
(b) What is deg(P)? 1
P connects to H and L, so deg(P) = 2.
(c) What is the total distance travelling H → S → L → P? 1
\(3 + 4 + 2 = 9\) km.

Question 12 3 marks Lesson 1

A weighted, directed network has edges A→B (6), B→C (2), A→C (10).

(a) What is the weight of the direct edge A→C? 1
The direct edge A→C has weight 10.
(b) What is the total weight travelling A→B→C? 1
\(6 + 2 = 8\).
(c) Which route from A to C has the smaller total weight? 1
Via B: weight 8, which is less than the direct edge's weight of 10.

Question 13 3 marks Lesson 2

A network has 5 vertices, and its minimum spanning tree is built from edges of weight 3, 5, 2 and 4.

(a) How many edges does its spanning tree contain? 1
A spanning tree of 5 vertices has \(5 - 1 = 4\) edges.
(b) What is the total weight of this minimum spanning tree? 1
\(3 + 5 + 2 + 4 = 14\).
(c) True or false: a network can have more than one minimum spanning tree with the same total weight. 1
True — when several edges share the same weight, more than one minimum spanning tree can achieve the same minimum total.

Question 14 4 marks Lesson 2

A network has vertices W, X, Y, Z with edges W–X (2), X–Y (2), Y–Z (2), W–Y (6), X–Z (7), W–Z (9).

(a) List the three edges included in the minimum spanning tree (in the order they'd be added). 2
W–X (2), X–Y (2), Y–Z (2) — each connects a new vertex without creating a cycle.
(b) What is the total weight of this minimum spanning tree? 1
\(2 + 2 + 2 = 6\).
(c) Is the edge W–Z included in the minimum spanning tree? 1
No — adding W–Z would create a cycle, since W and Z are already connected via W–X–Y–Z.

Question 15 3 marks Lesson 2

Using the same network as Question 14 (W, X, Y, Z), find the shortest path from W to Z.

(a) What is the weight of the direct edge W–Z? 1
The direct edge W–Z has weight 9.
(b) What is the total weight of the route W–X–Y–Z? 1
\(2 + 2 + 2 = 6\).
(c) What is the shortest path's total weight from W to Z? 1
6, via W–X–Y–Z (cheaper than the direct edge's weight of 9).
