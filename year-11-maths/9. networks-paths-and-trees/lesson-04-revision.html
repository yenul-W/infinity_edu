Quick Reference

Key Terms & Concepts

Lesson 1 — Network Concepts

  • Vertexan object or point in the network
  • Edgea connection between two vertices
  • Weighted / directededges labelled with a number / edges with a one-way arrow
  • Degreethe number of edges connected to a vertex

Lesson 2 — Shortest Paths & Spanning Trees

  • Path / treeroute with no repeated vertex / connected network with no cycles
  • Spanning tree / MSTa tree covering every vertex / the one with smallest total weight
  • Building an MSTadd edges smallest-to-largest, skip any that create a cycle
  • Shortest pathsmallest total weight route; not necessarily on the MST

Common Mistakes to Avoid

  • ! Confusing degree (number of edges at a vertex) with the total number of vertices in the network.
  • ! Forgetting that a spanning tree must include every vertex, not just some of them.
  • ! Adding an edge to a minimum spanning tree without first checking it wouldn't create a cycle.
  • ! Assuming the shortest path between two vertices must always be part of the minimum spanning tree.
  • ! Misreading a directed edge — an arrow means travel is only possible in that one direction.

Question 1 · Terminology

What is a vertex in a network?

A An object or point in the network
B A line connecting two objects
C The weight of an edge
D A cycle in the network
Answer: A
A vertex is an object or point in the network — edges are the lines connecting vertices.

Question 2 · Degree

A vertex has edges connecting it to 5 other vertices. What is its degree?

A 1
B 4
C 10
D 5
Answer: D — 5
Degree is the number of edges connected to the vertex — here, 5.

Question 3 · Directed Networks

In a directed network, an edge from S to T means:

A Travel is possible both ways
B Travel is only possible from S to T
C S and T are not connected
D The edge has no weight
Answer: B
A directed edge only permits travel in the direction the arrow points.

Question 4 · Constructing Diagrams

A distance table has no entry between Town A and Town D. What does this mean?

A There is no direct edge between A and D
B A and D have degree 0
C A and D are the same vertex
D A and D must be connected via all other towns
Answer: A
No table entry means no direct edge — A and D may still be reachable through other vertices.

Question 5 · Paths & Trees

What makes a network a tree?

A It contains at least one cycle
B Every vertex has the same degree
C It is connected and has no cycles
D All edges are directed
Answer: C
A tree is a connected network with no cycles.

Question 6 · Spanning Trees

What is a minimum spanning tree?

A The tree with the most edges
B The shortest path between two vertices
C Any network with weighted edges
D A spanning tree with the smallest possible total weight
Answer: D
A minimum spanning tree is the spanning tree whose edges have the smallest possible total weight.

Question 7 · Building an MST

A network has 8 vertices. How many edges are in its spanning tree?

A 6
B 9
C 8
D 7
Answer: D — 7
A spanning tree of a network with \(n\) vertices has \(n - 1\) edges: \(8 - 1 = 7\).

Question 8 · Building an MST

When building a minimum spanning tree, why might an edge be skipped even if it has a small weight?

A It is directed
B It connects a new vertex
C It would create a cycle
D It has too large a weight
Answer: C
An edge is skipped whenever it would create a cycle with the edges already chosen.

Question 9 · Shortest Path

Route A–B–C has total weight 9. The direct edge A–C has weight 6. What is the shortest path from A to C?

A Route A–B–C, weight 9
B Cannot be determined
C Both routes are equal
D Direct edge A–C, weight 6
Answer: D
6 is less than 9, so the direct edge A–C is the shortest path.

Question 10 · Mixed

A minimum spanning tree connects 5 towns with total weight 20. Why might the shortest route between two specific towns not use only MST edges?

A The MST always gives the shortest route between any two towns
B MSTs cannot include weighted edges
C The MST minimises the total weight overall, which can leave out a direct shortcut between one particular pair
D Shortest paths are never influenced by weight
Answer: C
The MST minimises total weight across the whole network, which can exclude a shortcut edge that would be the cheapest way between just one specific pair of towns.
