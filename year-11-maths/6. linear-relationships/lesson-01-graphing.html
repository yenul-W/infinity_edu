Part A

Tables of Values

Definition — Linear Function

A linear function is a rule that produces a straight-line graph. It has the form \(y = mx + b\), where every x-value maps to exactly one y-value. The relationship is called linear because equal changes in x always produce equal changes in y.

The graph of any linear function is an infinitely long straight line.

Part B

Gradient

Definition — Gradient

The gradient of a line (written \(m\)) measures its steepness and direction. It is calculated as:

\[m = \frac{\text{rise}}{\text{run}} = \frac{y_2 - y_1}{x_2 - x_1}\]

Choose any two points on the line. The gradient is the same regardless of which two points you pick.

↗ Positive (m > 0)
rises left-to-right
↘ Negative (m < 0)
falls left-to-right
→ Zero (m = 0)
horizontal line

Worked Example

Find the gradient of the line through (1, 3) and (4, 9).

rise = \(y_2 - y_1\) = 9 − 3 = 6

run = \(x_2 - x_1\) = 4 − 1 = 3

\(m = \dfrac{6}{3} = \mathbf{2}\)  — the line rises 2 units for every 1 unit across (positive gradient).

Part C

Y-Intercept

Definition — Y-Intercept

The y-intercept (written \(b\)) is the y-value where the line crosses the y-axis. Because any point on the y-axis has \(x = 0\), the y-intercept is always found by substituting \(x = 0\) into the equation.

In the equation \(y = mx + b\), the constant \(b\) is the y-intercept — it appears directly when the equation is in gradient-intercept form.

Worked Example

State the gradient and y-intercept of \(y = -2x + 5\).

Comparing with \(y = mx + b\):

  • Gradient: \(m = -2\) (the line falls left-to-right)
  • Y-intercept: \(b = 5\) (the line crosses the y-axis at \((0, 5)\))

The negative gradient means for every 1 unit we move right, we move 2 units down.

Quick method: If the equation is already in the form \(y = mx + b\), simply read off \(m\) (coefficient of x) and \(b\) (constant). If it is not in this form, rearrange it first — this is covered in Lesson 2.

Practice Questions

Multiple Choice

1. A line passes through the points (0, 6) and (2, 0). What is the gradient of this line? (1 mark)

A 3
B −3
C 2
D −2
Answer: B — gradient = −3
rise = 0 − 6 = −6, run = 2 − 0 = 2
\(m = \dfrac{-6}{2} = -3\). Negative because the line falls from left to right.

2. A line rises 12 units for every 4 units across. What is its gradient? (1 mark)

A −3
B −2
C 3
D 4
Answer: C — gradient = 3
\(m = \dfrac{\text{rise}}{\text{run}} = \dfrac{12}{4} = 3\). Positive because the line is rising.

3. Which of the following lines has a negative gradient and a positive y-intercept? (1 mark)

A \(y = 3x - 2\)
B \(y = -2x + 5\)
C \(y = 4x + 1\)
D \(y = -x - 3\)
Answer: B — \(y = -2x + 5\)
\(m = -2\) (negative ✓), \(b = 5\) (positive ✓). Option D has \(m = -1\) but \(b = -3\) (negative ✗).

4. The gradient of the line through \((-1, 1)\) and \((2, -5)\) is: (1 mark)

A 2
B −2
C −6
D −3
Answer: B — gradient = −2
rise = \(-5 - 1 = -6\), run = \(2 - (-1) = 3\)
\(m = \dfrac{-6}{3} = -2\)
