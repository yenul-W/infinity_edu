Reference

Formula sheet

Basic probability

\[0 \le P(E) \le 1 \qquad P(E) = \frac{\text{favourable outcomes}}{\text{total outcomes}}\]

The counting formula requires equally likely outcomes. All outcome probabilities sum to 1.

Complement

\[P(\text{not } E) = 1 - P(E) \qquad P(\text{at least one}) = 1 - P(\text{none})\]

Multistage events

\[P(A \text{ and } B) = P(A) \times P(B) \quad \text{(independent)}\]

On a tree: multiply along a path ("and"), add between paths ("or"). All path probabilities sum to 1.

Replacement

With — the bag is restored, probabilities unchanged, events independent.
Without — the favourable count and the total each fall by one, so the second draw depends on the first.

Frequency

\[\text{Relative frequency} = \frac{\text{occurrences}}{\text{trials}} \qquad \text{Expected frequency} = np\]

Relative frequency converges on the theoretical probability as trials increase. Expected frequency is a long-run average, not a guarantee.

Method

Which method do I use?

The question says…Use
"a fair die / fair coin / at random"Counting: favourable ÷ total
"in an experiment, X occurred \(k\) times"Relative frequency
"how many would you expect"Expected frequency \(np\)
"at least one"Complement: \(1 - P(\text{none})\)
"and" (both happen)Multiply
"or" (either happens)Add the separate paths
Two stages, few outcomesArray (table)
Three or more stages, or without replacementTree diagram
Two attributes cross-classifiedTwo-way table

The two questions to ask first

  1. Are the outcomes equally likely? If not, you need relative frequency.
  2. Is the item replaced? If not, both numbers change on the second draw.

Exam technique

Mistakes that cost marks

MistakeFix
Listing three outcomes for two coins HT and TH are distinct — there are four equally likely outcomes.
Adding when you should multiply "And" along a path means multiply. "Or" between paths means add.
Changing only the numerator without replacement Both the favourable count and the total drop by one.
Forgetting the second path for "one of each" RB and BR are both valid — add them.
Counting every case for "at least one" Use the complement: \(1 - P(\text{none})\).
Getting a probability above 1 Impossible. Usually caused by adding instead of multiplying.
Using the counting formula on a biased die Outcomes must be equally likely. Otherwise use relative frequency.
Rounding an expected frequency to a whole number unnecessarily An expected value of 47.5 is a valid long-run average.
Using the wrong denominator in a two-way table "Of those who…" restricts to a row or column total, not the grand total.
Quoting only relative risk Always give the absolute figures as well.
Not checking the tree paths sum to 1 A quick check that catches most branch errors.
