Reference

Method sheet

The scans

\[\text{EST} = \max(\text{previous EST} + \text{duration}) \qquad \text{(forward, from 0)}\] \[\text{LST} = \min(\text{next LST} - \text{duration}) \qquad \text{(backward, from } T)\]

Forwards: add and take the maximum. Backwards: subtract and take the minimum.

Float and criticality

\[\text{Float} = \text{LST}_{\text{end vertex}} - \text{EST}_{\text{start vertex}} - \text{duration}\]

Float 0 → critical. Float > 0 → non-critical, with that much slack. Float is never negative.

Three self-checks

  • The LST at the start vertex must be 0.
  • The EST at the finish vertex is the minimum completion time.
  • The critical path length equals that completion time, and its bars tile the Gantt chart with no gaps.

Dummies

Dashed, zero duration. Needed for overlapping dependencies (C needs A; D needs A and B) or uniqueness (two activities sharing both endpoints).

Changing durations

  • Shorten a non-critical activity → no change; float increases.
  • Shorten a critical activity → project shortens, but only down to the next-longest path.
  • Delay within float → absorbed. Delay beyond float → project slips by \((\text{delay} - \text{float})\).
  • With two critical paths, both must be shortened — or an activity lying on both.

Spreadsheet formulas

EFT \(=\) =C2+B2  ·  float \(=\) =E2-C2  ·  successor EST \(=\) =MAX(D2,D3)  ·  completion \(=\) =MAX(D2:D9). The MAX reproduces the entire forward scan.

Exam technique

Mistakes that cost marks

MistakeFix
Taking the minimum in the forward scan Take the maximum — work waits for every arriving activity.
Taking the maximum in the backward scan Take the minimum — the earliest deadline governs.
Adding durations of parallel activities Parallel activities run at the same time; take the later finish, not the sum.
Using the EST at the end vertex in the float formula Float uses EST at the start and LST at the end.
Getting a negative float Impossible — recheck both scans.
LST at the start vertex ≠ 0 An arithmetic error. Find it before continuing.
Drawing arrows for indirect predecessors Only immediate predecessors are drawn.
Giving a dummy a duration Dummies are always zero duration and always dashed.
Assuming shortening any activity helps Only critical activities affect the finish date.
Shortening past the next-longest path The project cannot go below the next path's length without shortening it too.
Missing a second critical path Check every zero-float chain — there may be more than one.
Forgetting units in the answer Days, weeks, hours — always state them.
